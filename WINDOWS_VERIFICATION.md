# Windows 11: план финальной проверки

Linux-среда разработки позволяет полностью проверить ядро, но не может загрузить
Windows App Runtime и визуально отрендерить WinUI 3. Этот чеклист рассчитан на
один проход в PyCharm на целевой Windows 11.

## 1. Окружение и старт

1. Установить CPython 3.13 x64 с python.org, создать `.venv`.
2. Установить `requirements.txt` и запустить `main.py`.
3. Если bootstrap предложит Windows App Runtime — установить и повторить запуск.
4. Убедиться, что окно открывается развёрнутым, меняет размер и содержит
   вертикальную прокрутку при меньшем дисплее.

## 2. Первая регистрация автозапуска

1. Проверить включённый тумблер «Автозапуск».
2. Открыть `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и проверить
   значение `JetBrainsVmoptionsTuner`: `pythonw.exe`, путь к `main.py`,
   `--background`.
3. Выключить/включить тумблер и убедиться, что значение удаляется/создаётся.

## 3. CRUD и JSON

1. Сделать копии двух настоящих `.vmoptions` в пользовательском каталоге.
2. Добавить две разные IDE через системный picker, отредактировать одну связку,
   удалить и добавить заново.
3. Создать общий набор, назначить обе IDE, добавить compatibility-строку кнопкой.
4. Создать второй набор и переназначить одну IDE: её значок должен исчезнуть из
   первого набора.
5. Проверить отказ сохранять строку без `-`.
6. Перезапустить приложение и сверить восстановление состояния из
   `%LOCALAPPDATA%\JetBrainsVmoptionsTuner\config.json`.

## 4. Редактор и синхронизация

1. Выбрать IDE в горизонтальной ленте: полное содержимое файла должно появиться,
   строки набора — стать зелёными.
2. Удалить одну обязательную строку вручную: должны появиться одновременно
   предложение сохранить и предупреждение синхронизации.
3. Проверить «Отменить изменения», затем ручное сохранение произвольной строки.
4. Удалить строку непосредственно из файла внешним редактором и нажать
   «Синхронизировать сейчас» — строка должна добавиться в конец.
5. Повторить «Синхронизировать все»; второй запуск не должен менять байты файлов.
6. Проверить CRLF и UTF-8 BOM на тестовой копии (`Format-Hex`).

## 5. Фоновый сценарий

1. Удалить назначенную строку, выполнить `python main.py --background`.
2. Убедиться, что окно не открылось, строка восстановлена, а
   `last_auto_sync` обновлён.
3. Повторить без изменения файлов — `last_auto_sync` обязан остаться прежним.
4. После входа в Windows проверить тот же сценарий через зарегистрированный
   автозапуск.

## 6. Оформление

1. Проверить системную, светлую и тёмную темы.
2. Применить `#00FF00`, закрыть и открыть приложение; цвет должен сохраниться.
3. Проверить отказ для `00FF00`, `#GGFF00` и короткого hex.

Если WinUI выдаёт ошибку импорта, сначала сверить, что все пакеты имеют одну
major-версию PyWinRT и что Python не установлен из Microsoft Store. Если XAML
Loader укажет строку разметки, исправлять следует только названное свойство,
после чего повторить весь раздел 1.
